관리자 자료 등록 안내

이 화면은 로그인 페이지가 아님. GitHub Pages는 정적 호스팅이므로 로그인·업로드 권한은 GitHub 계정과 저장소 권한으로 관리함. 주소를 숨기는 것만으로는 인증이 되지 않음.

자료 등록·교체·삭제

  1. GitHub 저장소에 로그인
  2. 1회차는 session1, 2회차는 session2, 참고자료는 etc 폴더를 선택
  3. Add file → Upload files를 이용해 파일 등록. 기존 파일은 동일 이름으로 교체하거나 GitHub에서 삭제
  4. main에 커밋 후 Actions에서 QA·GitHub Pages 배포 성공 여부 확인
  5. 수강생 자료실에서 해당 자료 링크 직접 확인
GitHub 저장소배포 결과

외부 링크 등록

etc 폴더에 JSON을 생성하고 아래와 같이 입력:

{"name":"참고 사이트","url":"https://example.com"}

업로드 자료는 공개될 수 있음. 비밀번호·토큰·민감정보를 등록하지 말 것.
